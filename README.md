# Diary Timeline Plugin for Obsidian

将所有日记文件按时间顺序串成连续时间线视图，类似 Logseq 日志页面。

## 功能特性

- 📅 **连续时间线视图**：所有日记按时间顺序排列，从上到下无限滚动
- 🔍 **正则筛选**：使用正则表达式筛选日志内容，高亮匹配项
- ✏️ **编辑功能**：双击条目可编辑，悬停点击 × 可删除
- ➕ **快速添加**：底部输入框直接添加新日志
- 📆 **日期分组**：每个日期作为分组标题，清晰区分
- 🔄 **多种加载模式**：可选择加载最近30天或全部日志

## 安装方法

1. 下载插件文件到 Obsidian 保险库的 `.obsidian/plugins/diary-timeline/` 目录
2. 重启 Obsidian
3. 在设置 → 社区插件中启用 "Diary Timeline"

## 日记格式要求

日记文件名格式：`YYYY-MM-DD.md`

日志条目格式：
```markdown
# 2026-08-22

- 09:00 开会讨论项目进度
- 14:30 编写代码实现功能
- 16:00 代码审查
```

## 使用方法

1. 点击左侧边栏的日历图标打开时间线视图
2. 或使用命令面板 (Ctrl/Cmd + P) 搜索 "打开日志时间线"

### 筛选日志
- 在顶部输入框输入正则表达式
- 实时显示匹配的条目
- 显示匹配计数

### 添加日志
- 在底部输入框输入内容
- 按 Enter 或点击 ➕ 按钮
- 自动添加到今天的日志

### 编辑日志
- 双击任意条目进入编辑模式
- 修改内容后按 Enter 保存
- 按 Esc 取消编辑

### 删除日志
- 将鼠标悬停在条目上
- 点击右侧出现的 × 按钮

### 导航
- 点击 "回到今天" 按钮快速定位到今天的日志
- 点击 "刷新" 按钮重新加载数据
- 点击 "全部/最近30天" 切换加载模式

## 设置选项

在设置 → Diary Timeline 中可以配置：

- **日记文件夹**：存放日记文件的路径（默认：/日志/）
- **默认加载天数**：打开时间线时加载的天数（默认：30天）
- **日期格式**：日记文件名的日期格式（默认：YYYY-MM-DD）
- **时间格式**：日志条目中的时间格式（默认：HH:mm）
